# Nebio Labs

Website for **Nebio Labs** — clothing, art, and textiles from Queens, NY.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Stack

- **Framework:** Astro 5
- **Styling:** Tailwind CSS
- **Fonts:** Raleway (headings) + DM Sans (body)
- **Shop:** Links to Etsy

## Pages

| Page | Route |
|------|-------|
| Home | `/` |
| Gallery | `/gallery` |
| About | `/about` |
| Shop | `/shop` |
| Contact | `/contact` |

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
